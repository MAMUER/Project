# Accessibility (a11y)

FitPulse интерфейс соответствует стандартам **WCAG 2.1 AA** и включает меры для соответствия **WCAG 2.2 AAA**.

## WCAG 2.1 AA (реализовано)

- Явные `<label>` для всех полей форм
- `aria-describedby` и `role="alert"` для ошибок валидации
- `aria-live` polite/assertive для динамических статусов
- Семантические теги `<main>`, `<nav>`, `<header>`
- Skip link для перехода к основному содержимому
- `:focus-visible` outline для клавиатурной навигации
- `prefers-reduced-motion` отключает анимации
- `forced-colors: active` адаптация для высококонтрастного режима
- Canvas fallback для графиков

## WCAG 2.2 AAA (реализовано)

### Тайм-ауты и динамика (2.2.1/2.2.2)

- Хук `usePauseState` позволяет пользователю принудительно ставить динамическое обновление на паузу
- Кнопка паузы/возобновления с `aria-pressed` и понятным `aria-label`
- Автоматическая пауза при `prefers-reduced-motion: reduce`

### Высококонтрастный режим (1.4.6/1.4.7)

- Медиа-запрос `@media (forced-colors: active)` переопределяет CSS-переменные на системные `Canvas`, `CanvasText`, `Highlight`, `Mark`
- Все интерактивные элементы получают явную границу `2px solid CanvasText`
- `forced-color-adjust: none` предотвращает сброс стилей системой

### Защита от миганий (2.3.1/2.3.2/2.3.3)

- Явное правило `@media (prefers-reduced-motion: reduce)` отключает все `animation` и `transition`
- Селекторы `[data-flash]`, `.flash`, `.blink` принудительно отключаются
- Документация запрещает добавлять мигающие/мерцающие элементы

### Семантика и навигация (1.3.1/2.4.1/2.4.6/2.4.7)

- Skip link `<a href="#main-content">` для перехода к основному содержимому
- Ландмарки: `<header>`, `<main id="main-content">`, `<nav aria-label="...">`
- Иерархия заголовков `<h1>` → `<h2>` → `<h3>`
- Модальные окна имеют `role="dialog"`, `aria-modal="true"`, `aria-label`, `aria-describedby`

### Текстовая альтернатива для не-текстового контента (1.1.1)

- Все emoji-иконки, не несущие смысла, помечены `aria-hidden="true"`
- Canvas-график имеет `role="img"`, `aria-label` и скрытый текстовый fallback
- Иконки в навигации имеют `aria-hidden="true"`, ссылки имеют `aria-label`

### Ошибки и подсказки (3.3.1/3.3.2/3.3.3)

- Каждая ошибка привязана к полю через `aria-describedby`
- Ошибки обёрнуты в `role="alert"` для немедленного объявления скринридером
- Ошибки содержат инструкции по исправлению:
  - "Заполните все поля. Email и текущий пароль обязательны для смены почты."
  - "Некорректный email. Используйте формат <name@example.com>."
  - "Введите пароль для подтверждения удаления аккаунта."

### Клавиатурное взаимодействие (2.1.1/2.1.2/2.4.3/2.4.5)

- Компонент `Modal` реализует trap focus: фокус циклически перемещается внутри модалки
- Escape закрывает модальное окно
- При закрытии модалки фокус возвращается на триггер
- Все интерактивные элементы доступны по Tab

### Адаптивный размер текста (1.4.4)

- Интерфейс использует относительные единицы и flex/grid layout
- Медиа-запросы адаптируют layout под мобильные/десктоп
- Контраст текста ≥ 4.5:1 для нормального размера, ≥ 3:1 для крупного

## Тестирование доступности

- React Testing Library проверяет семантику и ARIA-атрибуты
- Рекомендуется ручное тестирование с:
  - NVDA / JAWS (Windows)
  - VoiceOver (macOS / iOS)
  - TalkBack (Android)
- Автоматические проверки: axe-core, Lighthouse a11y audit

## Документация по компонентам

| Компонент | Доступность |
| ----------- | ------------- |
| `AuthScreen` | Labels, `aria-describedby`, `aria-live`, `role=alert`, контекстуальные ошибки |
| `Dashboard` | `aria-live` для метрик, canvas fallback, пауза обновлений, секции с `aria-label` |
| `Devices` | `aria-live` для статусов, `aria-label` для списка и кнопок |
| `Layout` | Skip link, `<main>`, `<nav>`, ландмарки |
| `Modal` | Trap focus, Escape, возврат фокуса, `aria-modal` |
| `Profile` | Labels, `aria-invalid`, `aria-describedby`, контекстуальные ошибки |
| `Admin` | Labels, `aria-label` для кнопок, контекстуальные ошибки |
